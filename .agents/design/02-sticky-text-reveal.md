# 第二轮设计：烟花粘附显字

> 状态：12 项体验决策已确认并已实现；自动化核验通过，浏览器观感、真机性能与视觉调参仍待完成。时长、半径等仍是待视觉验证的设计基线。
> 范围：替换首版“第七次爆炸后统一回流成字”的体验。与 [首版设计](01-product-and-architecture.md) 冲突时，本文件仅在显字相关范围内优先；其他产品与技术边界沿用首版。
> [现有实现规格](../spec/01-ascii-firework-v1.md) 尚未同步，不能直接作为本轮实现依据。

## 1. 体验目标

**文字像涂在夜空上的透明胶水。火花经过笔画时留住，一轮轮积累；十次互动后，缺口附近的小烟花自动补齐整句祝福。**

玩家应能感到“这些笔画是我刚才放的烟花留下的”，而不是“放够次数后播放了一段文字动画”。

- 开场没有可见文字底图、轮廓、占位点或完整文字遮罩。
- 从第一发爆炸起就有机会粘住火花；靠近爆炸的位置积累更多。
- 未接近笔画的火花正常飞散并熄灭。
- 已粘住的点不消失、不漂移、不被后来的烟花覆盖。
- 不要求每次任意落点都有新增文字；无新增点的有效爆炸仍计入十轮。
- 收尾也使用烟花带来的粒子填缺口，不突然淡入整句替代补齐。

## 2. 已确认的体验决策

| 维度 | 用户选择 | 设计含义 |
| --- | --- | --- |
| 吸附运动 | 经过笔画就粘住 | 自然扩散为主，接近笔画短暂减速固定；允许不显眼的局部引导 |
| 积累顺序 | 按烟花附近区域补全 | 点击位置有意义，不按字序，也不全句均匀发点 |
| 完成规则 | 积累几轮后自动收尾 | 不把所有覆盖责任交给玩家 |
| 触发时机 | 第十轮后 | 一轮是一发玩家烟花实际爆炸；自动烟花不计数 |
| 收尾表现 | 缺口附近分批小烟花 | 在缺口附近产生粒子，避免跨画面回流 |
| 收尾交互 | 继续放普通烟花 | 不锁发射、不重启收尾、不延后完成 |
| 粘点质感 | 固定发亮、轻微呼吸 | 落点固定，仅亮度缓慢变化 |
| 颜色 | 积累彩色，完成后统一 | 积累时保留来源色，全点落定后过渡为主题文字高亮色 |
| 进度提示 | 只给诗意提示 | 不显示轮数、百分比或任务进度条 |
| 提前查看 | 立即启动自动收尾 | 保留已有粘点，零轮也能启动，不直接跳成字 |
| 完成状态 | 祝福常驻，继续自由放 | 只在重放或更换祝福等重置操作时清空 |
| 重复命中 | 不改变文字 | 不重染、不局部闪亮、不叠加粘点 |

以上是内部设计决策，不新增十二组玩家设置。

## 3. 一次完整体验

1. 打开链接，只看到夜空、原有控件和诗意提示。
2. 玩家在左侧放烟花。火花扩散，靠近左侧隐藏笔画的部分火花减速粘住，其他火花消散。
3. 再往右侧放，右侧笔画也留下彩色碎点；左侧已有碎点保持不变。
4. 第 1–9 次爆炸持续局部积累。整句可能逐渐可辨，但不强行均匀补字。
5. 第 10 次玩家烟花爆炸仍正常积累，然后系统接续收尾；不必等该朵所有余烬消失。
6. 系统在未完成区域附近分批绽放小烟花，用短程飞散的火花填满剩余目标。玩家此时仍能放普通烟花。
7. 最后一颗补字粒子实际落定后，整句颜色柔和过渡到当前主题文字高亮色。
8. 祝福保持完整、明亮，仅有轻微亮度呼吸；后续烟花在文字后方燃放。

提前点击“让祝福完整绽放”时，从当前状态直接进入第 6 步。若十轮前已经自然补齐，则直接进入完成阶段，不再播放无意义的补洞表演。

### 文案基线

- 初始提示：**把烟花放在不同的地方，看看留下了什么。**
- 提前查看入口：**让祝福完整绽放**。
- 收尾提示：**还有几束光，正在找它们的位置。**
- 完成后不保留积累提示；沿用分享和重放入口，不增加自动庆祝一轮。

提示不得泄露祝福内容；初始提示在首次操作后短暂保留再淡出，具体驻留时间可在视觉验证时调整。

## 4. 吸附与补全规则

### 隐藏目标与粘点

开场即按当前祝福和视口生成不可见的文字采样目标。每个目标只有三种状态：**空闲、已预留且粒子在途中、已粘住**。

- 一点只允许一颗粒子占据；预留防止多颗火花争抢同一缺口。
- 完整度按“已粘住的有效采样点 / 全部有效采样点”计算，不按发射数、预留数或动画计时器计算。
- “完整”指所有有效目标都已占据，并且整个句子可读；不是填满原始字形的每一个像素。
- 目标采样必须覆盖每个字的主要笔画，不能为省预算遗漏整字。空格与空行不生成粒子目标。
- 积累过程中沿用现有 ASCII 字符美学，不改为圆点、贴图或普通字体覆盖。

### 自然积累

候选仅来自爆炸形成的火花，不把升空火箭和尾迹直接粘成笔画。火花靠近空闲目标时，可在小范围内轻微调整轨迹并减速，随后固定。

- 接触判断应考虑一帧内运动经过的线段，避免低帧率下跨过笔画却无法粘住。
- 不为一发远离文字的烟花分配另一侧的目标；允许该次只呈现普通烟花。
- 局部辅助优先调整爆炸时的一小部分速度方向，不在远处启动明显转向。
- 保留足够普通火花维持“烟花”的观感，不能整朵一炸就全冻在文字上。
- 粘住后保留来源颜色、固定字形和位置；亮度不低于可读基线。
- 火花再次经过已有粘点时照常飞过，不改变点位、颜色或亮度。

### 自动收尾

自然碰撞无法保证有限时间填满，因此收尾采用**缺口驱动的小烟花**，而不是等待运气。

1. 收尾只启动一次，停止让后续玩家烟花参与目标分配；它们仍完整呈现普通烟花效果。
2. 保留第十发及更早火花已获得的有效预留，避免收尾抢占目标。
3. 将剩余空闲目标按画面位置分成少量局部区域，逐批在附近生成小烟花；波大小和间隔在每次排程开始时固定，避免剩余批次越少、收尾反而越慢。
4. 每朵同时包含普通装饰火花与有明确目标的短程补字火花；绽放点必须偏离缺口质心，保证单点缺口也从可见爆炸位置飞来，而不是在终点直接生成。
5. 为补字火花安排有限时长的局部轨迹，在末段减速并落到目标上；不能用远处瞬移作为超时兜底。
6. 若自然积累阶段的预留粒子消失或失效，释放预留并重新安排附近补字火花，不能留下永久缺口。
7. 全部目标落定才完成；重复点击提前查看入口幂等，不重复安排表演。

正常模式不以直接绘制完整祝福、直接在终点生成可见粒子、或全屏火花回流作为收尾捷径。

### 节奏与颜色基线

| 参数 | 建议起点 | 不可破坏的语义 |
| --- | --- | --- |
| 局部接触范围 | 约一个采样间距内，按视口调整 | 只在附近粘住，不产生远程磁吸 |
| 接触后的减速 | 约 0.1–0.25 秒 | 短暂缓冲后固定，不持续游走 |
| 自动收尾 | 目标约 2–4 秒活动动画时间 | 最差落点也有限完成，不依赖用户继续操作 |
| 完成统一颜色 | 最后一颗落定后约 0.6–1 秒 | 只改变颜色，不改位置、不替换文字 |
| 稳定呼吸 | 轻微、低频的亮度变化 | 不含上下位移，不闪烁到不可读 |

这些值不暴露到编辑面板。若最大文本和低预算无法在收尾时长内兼顾可读性，应在视觉验证中调整批次与预算分配，不能牺牲完整补齐来硬守时长。

## 5. 状态与交互边界

复用现有阶段即可：`playing` 表示自由积累，`revealing` 改为自动收尾，`settled` 表示全点落定及之后。颜色过渡可作为完成态内部时间，不必增加完整状态框架。

| 场景 | 处理规则 |
| --- | --- |
| 第十次玩家爆炸 | 启动一次收尾；不能按点击次数或自动烟花计数 |
| 多发火箭同时在途 | 已经发射的继续燃放；进入收尾后新增爆炸只作普通烟花，不再次触发 |
| 点击提前查看 | 从当前覆盖状态启动收尾，包括零轮；保留已有彩色粘点 |
| 收尾中继续点击/按键 | 按原位置和节流规则发射普通烟花，不占补字预算、不延长收尾 |
| 完成后继续燃放 | 文字始终在前景，火花不修改文字 |
| 重放 | 清空粘点、预留、计数及收尾计划，以当前场景种子重新开始 |
| 空祝福 | 保持自由烟花；禁用或隐藏补全入口，不启动收尾 |
| 自然提前补齐 | 直接进入颜色统一和完成态，不等满十轮 |
| 页面隐藏 | 暂停动画时间与收尾调度；恢复后续播，不补发后台堆积批次 |

以下为未单独询问的工程默认，实施时遵循最小惊扰原则：

- **更改祝福文字**：新祝福使用新目标，重置积累和十轮计数，避免旧字残影被当作新进度。沿用输入防抖，不在每个输入事件反复执行昂贵采样。
- **仅更改配色**：保留覆盖与阶段；积累色映射到新主题，完成态统一到新主题高亮色。
- **重新生成种子、外部分享链接导航**：视为新场景，重置全部进度。
- **调整视口**：保持已完成的相对笔画区域和当前阶段。迁移前先把粒子、飞行起点和旧目标统一缩放到新视口坐标系，再按字序及字形内相对位置映射新目标；允许采样数量变化造成小幅覆盖差异，不能凭空补成整句。完成态重排后仍完整，收尾态重新安排剩余缺口。

## 6. 可访问性与性能

### 低动态模式

沿用 `prefers-reduced-motion`，不强制用户观看常规粒子运动：

- 保留十轮、局部积累和提前收尾语义，但用短淡入呈现局部新增粘点，减少飞行、闪烁并关闭呼吸。
- 自动收尾按局部批次柔和补点，不播放大幅运动；这是可访问性例外，不作为正常模式的偷懒路径。
- 沿用现有完成态可见 DOM 祝福兜底，保证较低粒子预算下长句可读；积累前不展示完整 DOM 文字。
- 完成时才通过现有辅助技术播报完整祝福，不每新增一点就播报。
- 现有原生控件、键盘发射、对话框操作及触摸目标保持可用。

### 粒子预算

沿用当前 Canvas 2D 和全局预算基线：普通模式 1,800，低动态模式 640（回写 2026-09 rev2：产品所有者视觉指示“更绚烂”，1200/420 → 1800/640，与单朵爆炸火花数同比例）。不引入新渲染库、物理引擎或后端。

- 文字目标上限必须为升空、装饰火花和补字飞行留出空间，不能先把全部预算用作永久粘点。
- 已粘住及有效预留的补字粒子不可被普通寿命淘汰或粒子上限裁剪删除。
- 预算不足时优先减少尾迹和装饰火花；仍遵守现有输入节流，不允许用户连点挤掉补字任务。
- 保证所有字的笔画分布后再降低采样密度；最大长度祝福需实测可读性。
- 用文字采样栅格或简单空间桶查询附近目标；不在每一帧执行所有火花与所有文字点的全量两两搜索。
- 空间分组只服务局部查询和收尾，不引入通用调度器或复杂最优匹配。

## 8. 验收清单

| 检查 | 通过标准 |
| --- | --- |
| 开场与首轮 | 无文字底图；第一发靠近笔画即可留下粘点，不等到第十轮才出现 |
| 局部性 | 在左/右区域分别燃放时，相应附近新增更多；远处不突然增加粘点 |
| 连续积累 | 已粘点不因寿命、后续爆炸或普通粒子裁剪消失 |
| 十轮计数 | 第十次玩家实际爆炸触发一次；连点、多火箭在途和自动爆炸不重复触发 |
| 偏置输入 | 十发全部放在同一侧甚至远离文字，自动收尾仍填齐所有有效目标 |
| 收尾来源 | 慢放可见补字火花从附近小烟花飞入；无全句淡入或远处瞬移 |
| 实际完成 | 在途粒子不算完成；零空闲、零在途且全部落定后才宣布完成 |
| 交互不中断 | 收尾中及完成后仍可发射；持续连点不拖延补齐、不破坏文本 |
| 颜色与固定感 | 积累时保留来源色，全部落定后统一主色；仅亮度呼吸，位置和字形不变 |
| 重复命中 | 文字不重染、不额外闪亮、不叠粒子 |
| 提前查看 | 零轮与中途均从当前状态补齐；连续点击不重启或重复收尾 |
| 重放与修改 | 重放/新祝福不继承旧占据或任务；仅换色不清空进度 |
| 视口变更 | 积累与收尾中旋转屏幕不突然完成、不全部清空；已完成文字仍完整 |
| 极端文本 | 短句、三行上限中文、混合标点都完整可读；空祝福保持自由烟花 |
| 低动态 | 减少运动、不闪烁、入口可跳过等待，完成态有可读文本兜底 |
| 性能 | 两档预算均不超限；收尾和连点不挤掉粘点，目标设备上实测帧时间 |

自动化至少覆盖：粘点持久性、目标占据去重、仅玩家爆炸计数、固定触发幂等、最差位置有限补齐、持续输入不阻塞、预算保护、重置取消旧任务及视口迁移不提前完成。

视觉验收必须补上录屏或浏览器人工观察：胶水感、局部性、粒子来源可见、长句可读性无法仅靠单元测试证明。
